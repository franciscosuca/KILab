Run with live models · configuration & safety

Open index.html and edit CONFIG.models in the script. Set each model's name, provider, protocol, base URL, model ID, and API key; then turn Mock responses off. The app supports OpenAI-compatible APIs (including LM Studio and compatible cloud proxies) and Ollama's chat API.

Live requests run from your browser, so the endpoint must allow CORS. API keys in this file are visible to anyone who can access it: use local-only credentials or a private proxy, never publish a key in a public copy. Mock mode is enabled by default.

HTML previews run in a sandboxed iframe, separate from this page. Response text is rendered as text, not injected as HTML.
