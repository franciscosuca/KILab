# Profile: <Your Name> (source of truth)

> Copy this file to `$CV_GENERATOR_HOME/profile.md` (default `~/.config/cv-generator/profile.md`) and fill it in. It stays on your machine and is never part of the skill. The agent may only use facts recorded here or stated in the conversation; keep it accurate and add new facts as they come up.

## Identity & contact
- Name · location · email · phone · LinkedIn · GitHub · website
- Languages with levels (CEFR) · certifications with years
- Education: degree, institution, year; thesis title/topic if relevant

## Roles (most recent first)
For each role: title, company, country, dates (MM/YYYY – MM/YYYY), one-line context, then **verified facts**:
- What you built / operated / owned, with tools and, only if known, measurable outcomes.
- Evidence source for each fact (repository, ticket, document) so claims can be re-checked.
- Wording on ownership (e.g. "contribute to / maintain", not "lead / own") if the exact scope matters.

## Projects & open source
- Name, link, one line on what it demonstrates, the concrete technologies and practices that are verifiable in the repository.

## Education / thesis details
- Research question, method, stack, results, and known limitations (do not turn limitations into claims).

## Do NOT claim
List anything a recruiter might assume that is not true or not provable:
- Tools you have not used in practice.
- Results that were only goals, grades or certifications you do not have.
- Ownership you do not hold; numbers you cannot source.

## Open questions to re-confirm
- Dates or titles that differ between sources, claims awaiting confirmation, QR/link targets.
