| Component | Minimum | Recommended |
|-----------|---------|-------------|
| CPU | Apple Silicon (M-series) | Apple M5 or newer |
| RAM | 16 GB unified memory | 32 GB unified memory |
| GPU VRAM | Unified memory (no dedicated VRAM) | Unified memory sized for target model (32 GB for 14B testing) |
