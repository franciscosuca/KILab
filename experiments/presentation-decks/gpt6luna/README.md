# Frontier Quality on Local Hardware

A responsive, single-page slide presentation built from the workshop preparation notes.

## Run

Open `index.html` in a browser, or serve this folder with any static file server:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000` from this folder.

## Navigation

- Scroll, swipe, or use the on-screen previous / next controls.
- Use the arrow keys, Page Up / Page Down, Space, Home, or End.
- Reduced-motion preferences are respected.
