Runtime details & safety

The server discovers LM Studio, oMLX, Ollama, and models available to your authenticated GitHub Copilot CLI. Selected models are shuffled into anonymous cards on every run. Mock responses are enabled by default; turn them off to call real models.

For authenticated local APIs, enter an API key or set the provider's environment variable (e.g. OMLX_API_KEY). If neither is supplied, OpenAI-compatible endpoints can reuse pi's key from ~/.pi/agent/models.json only when the Base URL matches exactly. Leaving the key field blank inherits server credentials. Keys are kept server-side and are not returned to the browser. Only loopback endpoints can be registered.

Local requests use the provider API; Copilot requests use the official CLI SDK. Results are saved in private operating-system temporary directories before display.

Generated HTML previews run in a sandboxed iframe. Response source is always rendered as text.
